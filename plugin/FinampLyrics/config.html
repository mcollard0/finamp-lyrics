Finamp Lyrics

Developed by mcollard0. Source and documentation · Report an issue · MIT license.

This release targets Jellyfin 10.11.11 on Linux. Install the Python worker and its dependencies, then configure the paths below.

Check Genius lyrics when music metadata is prefetched or playback begins. Replace existing lyrics only when the fetched text is longer.

Default and suggested: /usr/bin/python3
Default and suggested: /var/lib/jellyfin/finamp-lyrics/lyrics_fetcher.py. A replacement script must support the same queue arguments.
Default: empty. Optional suggested argument: --retry-429 to wait and retry rate limits, up to the worker timeout. For an option with a value, put the option and value on separate lines. No shell quoting is needed. Song ID, server, state, background count, delay, minimum plays and library arguments are supplied automatically using the fields below.
Default and suggested: http://localhost:8096/
Default and suggested: /var/lib/jellyfin/finamp-lyrics/state
Default and suggested: /var/lib/jellyfin/finamp-lyrics/credentials.json. Must be readable by the Jellyfin service account.
Default and suggested: 15. Increase if you want longer waits during rate-limit backoff.
Default: 3. Suggested: 3 for ordinary use, or 0 while the continuous batch worker handles background songs. The requested song is always prioritized.
Default and suggested: 2.
Initial delay: 0.5 seconds. Increases by 0.25 per request, capped at 10. Tune with --delay-step and --max-delay in Additional worker arguments.
